# Cursor Persian RTL & Vazirmatn Font

افزونه راست‌چین‌سازی خودکار و اعمال فونت زیبای **وزیرمتن (Vazirmatn)** برای پنل چت و محیط **Composer** در ویرایشگر هوش مصنوعی **Cursor**.

---

## ویژگی‌ها

- 🔤 **فونت استاندارد وزیرمتن (Vazirmatn)** به صورت آفلاین و آنلاین
- 🔄 **تشخیص خودکار جهت متن (Auto RTL / LTR)** برای پیام‌های فارسی و انگلیسی
- ⚡ **پشتیبانی کامل از Cursor Composer** و کادرهای متنی چندخطی
- 💻 **حفاظت کامل از بلوک‌های کد**: کدها همواره چپ‌چین (LTR) و با فونت مونو باقی می‌مانند
- 🛡️ **امنیت کامل دسترسی‌ها**: سازگار با اوبونتو ۲۴.۰۴ بدون دستکاری مخرب `chrome-sandbox`
- 🚫 **عدم تداخل با Antigravity IDE**: با شناسه، استایل‌ها و دستورات مستقل

---

## نحوه نصب و فعال‌سازی

### روش ۱: استفاده از اسکریپت مستقیم (ترمینال)

```bash
cd cursor
bash apply-cursor-persian.sh
```

جهت بازگردانی به حالت اولیه:
```bash
bash apply-cursor-persian.sh --restore
```

### روش ۲: نصب بسته VSIX در نرم‌افزار Cursor

۱. فایل پکیج شده `cursor-persian-chat-1.0.0.vsix` را تولید کنید:
```bash
npm run package
```
۲. در محیط Cursor از بخش Extensions گزینه **Install from VSIX...** را انتخاب کنید.
۳. دستور `Cursor Persian: فعال‌سازی راست‌چین و فونت وزیرمتن (Enable)` را از پالت دستورات (`Ctrl+Shift+P`) اجرا کنید.
