# افزونه راست‌چین خودکار چت و فونت وزیرمتن برای Antigravity IDE
## (Antigravity Persian RTL & Vazirmatn Font)

این افزونه محیط چت هوش مصنوعی **Antigravity IDE** را به صورت خودکار، هوشمند و بی‌نقص برای زبان فارسی راست‌چین (RTL) کرده و از فونت زیبای **وزیرمتن (Vazirmatn)** استفاده می‌کند.

---

### ویژگی‌های کلیدی:
1. **راست‌چین‌سازی خودکار و مستقل هر پاراگراف (Smart Paragraph-Level RTL):**
   - هر پاراگراف، لیست یا عنوان به طور مجزا بررسی می‌شود؛ جملات فارسی راست‌چین و جملات انگلیسی چپ‌چین باقی می‌مانند.
2. **نگارش استاندارد دو زبانه (Bilingual Text Flow):**
   - ترکیب کلمات انگلیسی در جملات فارسی باعث جابه‌جایی علائم نگارشی (نقطه، کاما، علامت سوال، پرانتز) نمی‌شود.
   - کدهای درون‌خطی (Inline Code مانند `` `npm install` ``) به صورت مجزا (Isolate) چپ‌چین و با فونت مونو‌اسپیس نمایش داده می‌شوند.
3. **حفاظت کامل از بلوک‌های کد (Code Blocks):**
   - بلوک‌های کد چندخطی (`<pre><code>...</code></pre>`) دست‌نخورده، چپ‌چین (LTR) و با فونت اختصاصی کد نمایش می‌یابند.
4. **فونت اصیل وزیرمتن (Vazirmatn):**
   - استفاده از فونت استاندارد وزیرمتن با وزن‌های متناسب و ارتفاع خط (Line-height: 1.85) بهینه‌سازی‌شده برای مطالعه راحت.
   - ثبت فونت به صورت محلی در سیستم‌عامل برای سرعت بارگذاری حداکثری بدون نیاز به اینترنت.
5. **پشتیبانی از استریمینگ زنده (Live Streaming):**
   - پردازش بدون لگ با `MutationObserver` بهینه‌شده به طوری که هم‌زمان با تایپ و پاسخ زنده Agent، راست‌چین بلافاصله اعمال می‌شود.
6. **راست‌چین خودکار کادر ورودی پرامپت (Prompt Input Box):**
   - هنگام تایپ پیام در چت، در صورتی که متن فارسی تایپ کنید، جهت کادر ورودی فوراً به راست‌چین تغییر می‌کند.
7. **رفع هوشمند خطای یکپارچگی فایل‌ها (Auto-Fix Checksums):**
   - با محاسبه و اصلاح خودکار هش‌های SHA-256 در `product.json`، از نمایش هشدار «Your installation appears to be corrupt» و برچسب `[Unsupported]` جلوگیری می‌شود.

### نحوه فعال‌سازی و نصب:

#### روش اول: از طریق ترمینال (سریع‌ترین روش)
تنها کافیست در ریشه این پروژه دستور زیر را اجرا کنید:
```bash
./apply-persian-rtl.sh
```
سپس در Antigravity IDE کلید `Ctrl+Shift+P` را زده و گزینه `Developer: Reload Window` را انتخاب کنید.

#### روش دوم: از طریق پالت دستورات Antigravity IDE
۱. در محیط نرم‌افزار، کلید‌های `Ctrl+Shift+P` را فشار دهید.  
۲. عبارت `Persian Chat` را جستجو کرده و گزینه:
   `Persian Chat: فعال‌سازی راست‌چین و فونت وزیرمتن (Enable)` را انتخاب کنید.  
۳. در صورت نیاز به دسترسی دسترسی نوشتن، گزینه **اجرا در ترمینال داخلی** را انتخاب نمایید.  
۴. پس از اتمام، دکمه **بارگذاری مجدد پنجره (Reload)** را بزنید.

---

### نحوه غیرفعال‌سازی و بازگردانی (Uninstall / Restore):
برای بازگردانی کامل به حالت پیش‌فرض بدون هیچ تغییری:
- از طریق ترمینال:
  ```bash
  ./apply-persian-rtl.sh --restore
  ```
- یا از طریق منوی دستوری IDE:
  `Persian Chat: غیرفعال‌سازی و بازگردانی (Disable)`
